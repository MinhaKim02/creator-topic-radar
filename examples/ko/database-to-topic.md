# 데이터베이스에서 소재 찾기

## 요청

```text
$creator-topic-radar를 사용해 아래 가상 백로그를 오프라인으로 평가해줘.
기준 시각은 2026년 10월 1일 12:00 UTC야. 검색하거나 출처를 만들지 마.
현재 소비자에게 중요한 소재를 최대 3개 원해. 기존 콘텐츠 목록은 없어.
미확인 사항을 밝히고 후보 추천에서 멈춰줘.
```

## 가상 입력

| 기록 | 기록 생성일 | 실제 사건으로 적힌 날짜 | 출처·수치 |
|---|---|---|---|
| B1: 제조사 B가 수리 가능한 책상 조명 출시 | 2026-10-01 | 2026-05-01 | 출처와 후속 변화 없음. activity score 92, 의미는 모름 |
| B2: 제조사 C가 조명 교체 스위치 제공 발표 | 2026-09-30 | 2026-09-29 | 가상 발표문 발췌에는 스위치를 주문할 수 있다고만 적힘. 수리비 근거 없음 |

이 기록은 모두 가상이며 실제 사건을 입증하지 않습니다. 제한된 근거를 어떻게 처리하는지 확인하기 위한 오프라인 예제입니다.

## 처리 예시 — 실제 리서치 결과 아님

- **B1:** 기록은 새로 만들어졌지만 적힌 출시는 과거 사건입니다. 사실 근거는 부족합니다. 정의를 모르는 activity score를 검증이나 외부 관심도로 해석하지 않습니다. 최신 사건으로 추천하지 않습니다.
- **B2:** “스위치를 교체할 수 있으면 이 조명을 유지하는 비용이 줄어들까?”라는 잠정 질문을 만들 수 있습니다. 제공된 발표문은 가상 제조사가 부품을 제공한다고 주장했다는 것만 뒷받침하며, 전체 수리비는 입증하지 않습니다. 제공된 날짜 안에서는 최근 발표지만 현실의 현재 상태는 검증되지 않았습니다.
- **두 기록 공통:** 크리에이터 근거와 기존 콘텐츠가 없으므로 관심도와 중복 위험은 미평가입니다. B2의 비용 질문은 답을 사실로 추천하기 전에 추가 근거가 필요합니다. 부품 제공 여부만 다루는 좁은 질문은 범위를 유지하면 60초에 맞을 수 있습니다. 이 자료만으로 검증된 현실의 추천 목록을 만들 수는 없습니다.

실제 조사에서는 출처 링크나 권한 있는 아카이브 접근을 요청하고, 현재 상태와 크리에이터 신호를 확인한 뒤 제공된 기존 콘텐츠와 비교합니다. 흥미로운 기록이라도 바로 제작할 수 있는 소재는 아닐 수 있습니다.

## 가상 후보와 인계 요약 전체 예시

이 추가 예시에 한해 S1이라는 가상 발표문을 제공했다고 가정합니다. 제목은 “Replacement lamp switches”, 발행일은 2026-09-29이며 기준 시각 이전에 확인 가능합니다. 발췌 전문은 “Maker C announces that owners of model C1 may order replacement switches starting today.”입니다. S1은 예제 안의 자료 식별자이며 실제 출처 링크가 아닙니다. 발표가 있었다는 것은 예제 안에서 뒷받침하지만 실제 재고나 수리 성공을 검증하지 않습니다.

**조사 맥락:** 일상용품을 관리하는 소비자; 2026-10-01 12:00 UTC까지 최근 7일; 오프라인 데이터베이스 중심 평가; 크리에이터 수치와 기존 콘텐츠 없음.

**추천: 1개(가상 자료 범위).**

- **가제:** 제조사 C, C1 모델 교체 스위치 제공 발표.
- **핵심 질문:** 이번 발표는 C1 사용자에게 어떤 선택지를 제공하나?
- **설명할 내용:** 사용자가 교체 스위치를 주문할 수 있다고 발표했습니다[S1]. 부품 제공 발표이며 수리비 절감이 입증된 것은 아닙니다.
- **시청자 관련성:** 특정 부품의 교체 가능성은 사용자에게 구체적인 관리 질문을 제공합니다. 관찰된 관심은 모릅니다.
- **날짜·최신성:** 발표일 2026-09-29, 기록 생성일 2026-09-30. 요청 기간 내 최근 발표입니다.
- **시청자 관심도:** 미평가. 확인한 크리에이터 관찰 자료가 없습니다.
- **사실 근거:** 발표 내용에 한해 뒷받침됨[S1]. 부품 제공 여부는 기업 주장입니다. 실제 배송, 비용, 수리 성공은 미확인입니다.
- **중복 위험:** 미평가. 기존 콘텐츠가 없습니다. 추천이 하나이므로 후보끼리 겹치는 항목은 없습니다.
- **숏폼 적합성:** 높음. 하나의 발표와 한계를 다루는 범위입니다.
- **주의점:** 모든 모델에 해당한다거나 재고가 독립 검증됐다거나 수리가 저렴해졌다고 표현하지 않습니다.
- **기록 연결:** B2의 발표와는 직접 일치하며 비용 절감 질문에는 부분 일치입니다.
- **조사 공백:** 가격, 재고, 설치 요건, 크리에이터 관심, 기존 콘텐츠.
- **추천 판단:** 이 가상 평가 안에서 좁은 발표 소재를 추천합니다. 현실의 검증을 수행했다는 뜻은 아닙니다.

**잠정 후속 질문: 1개.** 스위치 교체가 전체 수리비를 낮출까? 부품 가격·배송비·작업비와 적절한 수리·교체 비교가 필요합니다. 두 번째 추천 소재가 아닙니다.

**발표 소재를 선택하고 인계를 요청한 경우:** 핵심 질문은 C1 사용자에게 어떤 선택지가 발표됐는지입니다. 뒷받침되는 사실은 제조사 C의 날짜가 명시된 발표[S1]이며, 기업 주장은 사용자가 스위치를 주문할 수 있다는 것입니다. 기준 시각은 2026-10-01 12:00 UTC입니다. 모델 범위를 유지하고 실제 재고·비용·성공 여부는 미확인으로 남깁니다. 내레이션이나 장면 구성은 제공하지 않습니다.
