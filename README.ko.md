# Creator Topic Radar

출처와 명확한 질문, 미확인 사항을 함께 제시하는 숏폼 소재 리서치용 Agent Skill입니다.

크리에이터 영상, 최근 사건, 조사 백로그에서 후보를 찾습니다. 관심도·최신성·사실 근거·중복 위험·약 60초 분량의 적합성을 각각 평가합니다. YouTube Shorts, TikTok, Instagram Reels 등을 만드는 크리에이터, 콘텐츠 마케터, 리서처를 위한 절차입니다.

**버전:** v0.1.0 · **라이선스:** [MIT](LICENSE)

## 언제 사용하나요?

| 하고 싶은 작업 | 출발점 | 스킬이 하는 일 |
|---|---|---|
| 이번 주에 다룰 소재 찾기 | 크리에이터 영상 | 반복되는 질문을 찾고 실제 사건을 검증 |
| 제품·기업의 소식을 소재로 만들기 | 기업·제품 또는 발표 | 근거가 뒷받침하는 구체적인 시청자 질문 찾기 |
| 쌓아둔 조사 자료 검토하기 | 기록·노트·아카이브 | 최근 변화, 과거 사건, 근거 부족한 주장을 구분 |

소재 추천에서 작업을 마칩니다. 소재를 선택한 뒤 요청하면 사실 중심의 인계 요약을 제공합니다. 대본, 장면 구성, 발행은 별도 작업입니다.

## 시작하기

스킬을 불러오거나 파일을 읽을 수 있는 AI 에이전트가 필요합니다. 실시간 조사에는 웹 출처 접근도 필요하며, 제공된 자료의 평가는 오프라인으로 할 수 있습니다. 이 저장소에는 실행 지침이 들어 있으며 플랫폼 API나 데이터베이스 연결 도구는 포함되지 않습니다.

### 설치

**Claude Code**에서 사용하려면 작업할 프로젝트 폴더의 터미널에서 아래 명령을 실행합니다. Node.js/npm과 Git이 필요합니다.

```sh
npx skills@1.7.0 add MinhaKim02/creator-topic-radar \
  --skill creator-topic-radar --agent claude-code --copy --yes
```

프로젝트의 `.claude/skills/creator-topic-radar/`에 스킬이 복사됩니다. Skills CLI 1.7.0으로 프로젝트 설치와 참고 파일을 확인했습니다. [Skills CLI 안내](https://github.com/vercel-labs/skills)와 [Claude Code 스킬 안내](https://code.claude.com/docs/en/skills)를 참고하세요.

다른 환경에서는 해당 환경이 안내하는 스킬 경로를 사용합니다. **Code → Download ZIP**으로 저장소를 받아 `SKILL.md`와 `references/`를 함께 유지하세요. 자동 로딩을 지원하지 않으면 파일을 읽을 수 있는 에이전트에 `SKILL.md`와 연결된 참고 문서를 읽고 따르도록 요청합니다.

### 소재 요청

Claude Code에서는 `/creator-topic-radar`를 호출하고 조사 조건을 적습니다. 다른 환경의 호출 방식은 다를 수 있습니다.

```text
/creator-topic-radar
일상용품 수리에 관심 있는 소비자를 위한 최근 7일 소재를 최대 3개 찾아줘.
크리에이터의 YouTube 영상에서 시작해 실제 사건을 검증하고,
첨부한 기존 콘텐츠 목록과 비교해줘. 시간대는 UTC로 해줘.
출처·주의점·부족한 근거를 포함하고 후보 추천에서 멈춰줘.
```

시청자, 주제 범위, 조사 기간, 플랫폼과 가능한 경우 기존 콘텐츠를 제공합니다. 중요한 맥락이 빠지면 확인하거나 가정을 밝힙니다. 별도 요청이 없으면 사용자 언어로 결과를 작성합니다. 사용 권한이 있는 자료만 제공하세요.

## 입력에서 판단까지

아래는 **가상 예시**입니다. 2026년 10월 1일을 기준으로 최근 7일을 조사한다고 가정합니다.

| 제공된 입력 | 판단 결과 |
|---|---|
| 10월 1일 생성한 기록에 5월 1일 출시가 적혀 있고 후속 변화 없음 | 최신 출시로 처리하지 않음. 기록 생성일과 사건일을 구분 |
| 5월 출시 이후 9월 29일 교체 부품 발표문이 제공됨 | 새 발표를 검토하되 수리비 절감까지 입증된 것으로 판단하지 않음 |
| 두 후보의 제목은 다르지만 사건·원리·시청자가 얻을 이해가 같음 | 후보를 합친 뒤 추천 개수를 계산 |

각 추천 후보에는 가제, 하나의 핵심 질문, 영상이 설명할 내용, 시청자 관련성, 날짜, 출처, 다섯 평가 항목, 주의점과 조사 공백이 포함됩니다. 크리에이터 근거가 없으면 관심도는 미평가이며, 기존 콘텐츠가 없으면 과거 콘텐츠와의 중복 위험은 미평가입니다.

[가상 후보와 인계 요약 전체 예시](examples/ko/database-to-topic.md) 또는 [출력 템플릿](references/output-template.md)을 확인하세요. 실제 조사 결과가 아닌 형식 설명용 예제입니다.

## 한계와 검증

검색 범위와 플랫폼 수치는 도구에 따라 다릅니다. 크리에이터 인기가 주장을 검증해주지는 않으며, 공식 발표가 시청자 관심을 입증하지도 않습니다. 오프라인 분석은 이후 현실의 변화를 확인할 수 없습니다. 중복 검사는 제공된 기존 콘텐츠와 확인한 후보 범위에 한정됩니다.

요청한 수보다 적게 추천하거나 추천하지 않을 수 있습니다. 바이럴 성과, 조회수, 사실 정확성, 조사 시간 절감을 보장하지 않습니다.

Skills CLI의 스킬 발견과 프로젝트 파일 설치를 확인했습니다. 이 확인에는 Claude Code의 실제 스킬 활성화와 실시간 조사가 포함되지 않습니다. 검증 사례는 평가용 명세이며 전체 통과나 성능 벤치마크를 주장하는 자료가 아닙니다. [실행 절차](tests/cases.md#run-protocol)를 참고하세요.
